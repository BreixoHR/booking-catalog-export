# Historial de versiones

## 2.0.0 · 2026-10-06: versión pública
- Paquete Python sin dependencias con un modelo común para todas las plataformas.
- Clasificación de tipos de cliente por rango de edad y palabras clave multilingües (corrige "Niños (6-10)" → bebé).
- Credenciales por variables de entorno, tope de llamadas, `Money` exacto y exportación a Things To Do.
- 11 tests con servidores HTTP que verifican la firma HMAC y la renovación del token.
